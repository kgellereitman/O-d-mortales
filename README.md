README
La pagina "Oid Mortales" cuenta con el objetivo de facilitar la informacion imparcial sobre la política argentina.
Esta enfocada principalmente para jovenes empadronados (entre 16 y 20 años).
 Limitaciones: 
1. La pagina no cuenta con una base de datos por lo que no se pueden crear cuentas. 
2. No contamos con la IA  entrenada para filtrar mensajes en el foro.
3. No contamos con los contactos de los políticos correspondientes para responder en el foro.
4. No contamos con un sistema de actualización de la información.
 Funcionalidades:
La página web cuenta con 15 páginas que entre ellas se encuentran las siguientes interacciones:
Un mapa de Argentina donde se puede seleccionar cada provincia y obtener información,
Un foro público y anónimo donde publicar preguntas y respuestas
